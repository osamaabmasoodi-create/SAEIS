# 🛡️ SAEIS - Smart Audit & ERP Integration System
**نظام التدقيق المالي الآلي والربط الذكي مع أنظمة ERP**

نظام ذكي يعتمد على الذكاء الاصطناعي والمعايير الدولية للتقارير المالية (IFRS/IAS) للتحقق التلقائي من القيود المحاسبية، اكتشاف المخالفات، واقتراح قيود التصحيح الهيكلية.

---

## 📊 1. ميزات لوحة التحكم الرئيسية (CFO Dashboard)

تتيح لوحة التحكم للمدراء الماليين (CFOs) والمراجعين نظرة شاملة وفورية على سلامة البيانات المالية:

* **معدل الامتثال للمعايير (Compliance Rate):** مؤشر إحصائي فوري لنسبة القيود المطابقة للمعايير الدولية.
* **إحصائيات القيود المخالفة:** تتبع دقيق لعدد القيود التي تحتوي على خطأ معالجة أو مخالفة معيارية.
* **تحليل المخاطر المالي التفاعلي:** توزيع المخاطر حسب المعيار (IAS 2, IAS 16, IFRS 9, IFRS 16) مع إمكانية التصفية التفصيلية.
* **مراقبة الانحرافات:** تنبيهات فورية للممارسات المحاسبية الخاطئة المؤثرة على القوائم المالية.

---

## ⚖️ 2. قواعد الفحص التلقائي المطبقة (IFRS & IAS Rules)

يعتمد المحرك الذكي على قواعد تدقيق برمجية للتحقق من المعالجات التالية:

* **IAS 2 (المخزون - Inventory):**
  * فحص صافي القيمة القابلة للتحقق (NRV).
  * اكتشاف حالات عدم إثبات مخصص انخفاض قيمة المخزون عند هبوط أسعار السوق.
* **IAS 16 (الأصول الثابتة - PPE):**
  * التمييز بين المصاريف التشغيلية (Maintenance Expenses) والتكاليف الرأسمالية (Capital Expenditure).
  * اكتشاف ورأسمالة مصاريف الصيانة الدورية بشكل خاطئ واقتراح قيود الفصل التصحيحية.
* **IFRS 9 (الأدوات المالية - Financial Instruments):**
  * تطبيق نموذج الخسائر الائتمانية المتوقعة (ECL Model) على أعمار الذمم المدينة (Aging Schedule).
  * الاحتساب التلقائي لمخصص الديون المَشكوك في تحصيلها طبقاً للمصفوفة الائتمانية.
* **IFRS 16 (عقود الإيجار - Leases):**
  * التحقق من المعالجة الرأسمالية لعقود الإيجار التشغيلية طويلة الأجل.
  * إثبات أصل حق الاستخدام (ROU Asset) والالتزام مقابل الإيجار (Lease Liability) بدلاً من الإثبات كمصروف مباشر.

---

## 🔌 3. الربط التكاملي مع أنظمة ERP عبر الـ API

يوفر النظام بوابات ربط مرنة (ERP Connectors) للاتصال المباشر مع مختلف الأنظمة المحاسبية:

* **الأنظمة المدعومة:**
  * Odoo Enterprise / Community
  * SAP ERP / S/4HANA
  * Onyx Pro (أونكس برو)
  * Custom Webhooks / REST APIs
* **آلية التكامل:**
  * **سحب القيود (Fetch GL Entries):** قراءة القيود اليومية وحركة الحسابات تلقائياً عبر API Endpoint.
  * **الفحص اللحظي (Real-time Validation):** معالجة القيود فور إدخالها قبل الإقفال النهائي.
  * **تصدير قيود التسوية (Post Adjustments):** إرسال قيود التصحيح المقترحة (Adjusting Entries) مباشرة إلى نظام الـ ERP بعد اعتمادها.
